# المساهمة في Pinoox

[← العودة إلى الفهرس](../README.md)

Pinoox مشروع مفتوح المصدر. مساهماتك — من تقارير الأخطاء (Bug Reports) إلى طلبات السحب (Pull Requests) — تساعد في تحسين الإطار ووثائقه.

---

## طرق المساهمة

| النوع | الوصف |
|------|-------------|
| تقرير خطأ (Bug report) | فتح Issue على GitHub مع خطوات إعادة الإنتاج |
| طلب ميزة (Feature request) | فتح Issue يصف حالة الاستخدام |
| Pull Request | إصلاح خطأ أو إضافة ميزة في المستودع المناسب |
| الوثائق | تحسين الملفات ضمن `docs/` (بالفارسية أو الإنجليزية) |
| تطبيق مفتوح المصدر | نشر تطبيق Pinoox للمجتمع |

---

## الإبلاغ عن الأخطاء

عند فتح Issue، أرفق ما يلي:

1. **العنوان** — ملخص قصير للمشكلة
2. **خطوات إعادة الإنتاج** — خطوة بخطوة
3. **السلوك المتوقع** مقابل **السلوك الفعلي**
4. **البيئة** — إصدار PHP، إصدار Pinoox/pincore، نظام التشغيل
5. **كود نموذجي** — إن أمكن

[Pinoox GitHub Issues](https://github.com/pinoox/pinoox/issues)

---

## طلبات السحب (Pull Requests)

### المستودعات

- **pinoox/pinoox** — المشروع النموذجي، تطبيقات النظام، المشغّل (launcher)
- **pinoox/pincore** — نواة الإطار (`vendor/pinoox/pincore/`)

أرسل تغييرات النواة إلى pincore، وليس فقط إلى النسخة المحلية في `vendor/` داخل مشروعك.

### استراتيجية الفروع (3.x)

- **إصلاحات الأخطاء** → الفرع المستقر الحالي (مثل `3.x`)
- **الميزات الصغيرة المتوافقة** → نفس الفرع المستقر
- **التغييرات الجذرية أو الكبيرة** → فرع `master` / فرع الإصدار التالي

### معايير الكود

- [PSR-12](https://www.php-fig.org/psr/psr-12/) لأسلوب الكود
- [PSR-4](https://www.php-fig.org/psr/psr-4/) للتحميل التلقائي (autoloading)
- PHP 8.2+
- رسائل commit واضحة وبصيغة الأمر (مثل `Fix route validation for missing actions`)
