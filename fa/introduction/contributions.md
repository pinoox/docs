# مشارکت در توسعه پینوکس

[← بازگشت به فهرست](../../readme-fa.md)

پینوکس یک پروژه متن‌باز است. مشارکت شما — از گزارش باگ تا Pull Request — به بهبود فریمورک و مستندات کمک می‌کند.

---

## روش‌های مشارکت

| نوع | توضیح |
|-----|--------|
| گزارش باگ | Issue در گیت‌هاب با مراحل بازتولید |
| پیشنهاد قابلیت | Issue با توضیح use case |
| Pull Request | رفع باگ یا افزودن feature در مخزن مناسب |
| مستندات | بهبود فایل‌های `docs/` (فارسی یا انگلیسی) |
| اپ متن‌باز | انتشار اپ پینوکسی برای جامعه |

---

## گزارش باگ

هنگام ثبت Issue این موارد را بنویسید:

1. **عنوان** — خلاصه مشکل
2. **مراحل بازتولید** — گام‌به‌گام
3. **رفتار مورد انتظار** در مقابل **رفتار فعلی**
4. **محیط** — نسخه PHP، پینوکس/pincore، سیستم‌عامل
5. **نمونه کد** — در صورت امکان

[Issues گیت‌هاب پینوکس](https://github.com/pinoox/pinoox/issues)

---

## Pull Request

### مخزن‌ها

- **pinoox/pinoox** — پروژه نمونه، اپ‌های سیستمی، launcher
- **pinoox/pincore** — هسته فریمورک (`vendor/pinoox/pincore/`)

تغییرات هسته را در pincore ارسال کنید، نه فقط در `vendor/` پروژه محلی.

### استراتژی شاخه (نسخه ۳.x)

- **رفع باگ** → شاخه پایدار فعلی (مثلاً `3.x`)
- **feature کوچک و سازگار** → همان شاخه پایدار
- **تغییرات breaking یا major** → `master` / شاخه نسخه بعد

### استاندارد کد

- [PSR-12](https://www.php-fig.org/psr/psr-12/) برای سبک کد
- [PSR-4](https://www.php-fig.org/psr/psr-4/) برای autoload
- PHP 8.1+
- پیام commit واضح و imperative (مثلاً `Fix route validation for missing actions`)
