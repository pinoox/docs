# پینوکس چیست؟

پینوکس یک فریمورک PHP متن‌باز و مدرن (نسخه ۳.x) است که با معماری HMVC و مفهوم «اپ»، توسعه وب‌اپلیکیشن‌های ماژولار را ساده می‌کند. هر اپ یک واحد MVC مستقل در `apps/{package}/` است و هسته مشترک فریمورک در `vendor/pinoox/pincore/` قرار دارد.

---

## معماری اپ‌محور

در یک نصب پینوکس، چند اپ مستقل کنار هم کار می‌کنند:

```
{project_root}/
├── index.php              ← ورودی وب
├── pinoox                 ← ورودی CLI
├── composer.json
├── vendor/pinoox/pincore/ ← هسته فریمورک (فقط برای تغییرات خود فریمورک)
└── apps/
    ├── com_pinoox_manager/
    └── com_example_blog/  ← اپ شما
```

- **پروژه** = پوشه‌ای که `index.php` و `apps/` دارد (نام پوشه مهم نیست).
- **اپ** = ماژول کامل با کنترلر، مدل، مسیر، تم و تنظیمات خودش.
- **هسته** = موتور مشترک (روتر، HTTP، دیتابیس، Twig، CLI و …).

منطق کسب‌وکار را در `apps/` بنویسید، نه در `vendor/pinoox/pincore/`.

---

## چرخه یک درخواست HTTP

```
مرورگر → index.php → bootstrap
      → انتخاب اپ فعال (دامنه یا prefix مسیر)
      → بارگذاری app.php و routes/
      → Flowها → Controller → Model (اختیاری) → View یا JSON
```

---

## نام‌گذاری اپ

فرمت پیشنهادی پکیج:

```
com_{vendor}_{name}
```

مثال: `com_acme_shop` — نام پوشه، مقدار `package` در `app.php` و بخش namespace باید یکسان باشند.

---

## برای چه پروژه‌هایی مناسب است؟

- سایت‌ها و پنل‌های چندبخشی که هر بخش می‌تواند اپ جدا باشد
- تیم‌هایی که می‌خواهند ماژول‌ها را مستقل توسعه، تست و نگه‌داری کنند
- پروژه‌های PHP 8.2+ با Composer و CLI یکپارچه (`php pinoox …`)
