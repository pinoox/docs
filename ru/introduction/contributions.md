# Участие в развитии Pinoox

[← Вернуться к оглавлению](../README.md)

Pinoox — проект с открытым исходным кодом. Ваш вклад — от сообщений об ошибках до pull request'ов — помогает улучшать фреймворк и его документацию.

---

## Способы участия

| Тип | Описание |
|------|-------------|
| Сообщение об ошибке | GitHub Issue с шагами воспроизведения |
| Запрос новой функции | Issue с описанием сценария использования |
| Pull Request | Исправление ошибки или новая функция в соответствующем репозитории |
| Документация | Улучшение файлов в `docs/` (персидский или английский) |
| Open-source-приложение | Публикация приложения Pinoox для сообщества |

---

## Сообщения об ошибках

При открытии Issue укажите:

1. **Заголовок** — краткое описание проблемы
2. **Шаги воспроизведения** — шаг за шагом
3. **Ожидаемое поведение** и **фактическое поведение**
4. **Окружение** — версия PHP, версия Pinoox/pincore, операционная система
5. **Пример кода** — по возможности

[Pinoox GitHub Issues](https://github.com/pinoox/pinoox/issues)

---

## Pull request'ы

### Репозитории

- **pinoox/pinoox** — пример проекта, системные приложения, лаунчер
- **pinoox/pincore** — ядро фреймворка (`vendor/pinoox/pincore/`)

Отправляйте изменения ядра в pincore, а не только в локальную копию `vendor/` в вашем проекте.

### Стратегия веток (3.x)

- **Исправления ошибок** → текущая стабильная ветка (например, `3.x`)
- **Небольшие совместимые функции** → та же стабильная ветка
- **Ломающие или крупные изменения** → `master` / ветка следующей версии

### Стандарты кода

- [PSR-12](https://www.php-fig.org/psr/psr-12/) для стиля кода
- [PSR-4](https://www.php-fig.org/psr/psr-4/) для автозагрузки
- PHP 8.1+
- Чёткие сообщения коммитов в повелительном наклонении (например, `Fix route validation for missing actions`)
