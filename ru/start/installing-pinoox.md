# Установка Pinoox

[← Вернуться к оглавлению](../README.md)

В этом руководстве описывается установка Pinoox 3.x. Есть два способа начать:

| Путь | Лучше всего подходит для |
|-------|----------|
| **A. Одно приложение с [Pinx CLI](./pinx-cli.md)** | Создание одного приложения — самый быстрый старт, без UI менеджера |
| **B. Полная платформа (классический)** | Размещение нескольких приложений с графическим установщиком и менеджером |

---

## Требования

| Инструмент | Версия |
|------|---------|
| PHP | 8.1 или выше (с ext-mysqli, ext-zip) |
| MySQL / MariaDB | 5.7+ |
| Composer | 2.x |
| Node.js (опционально) | 18+ — только для сборки фронтенд-тем |

---

## Путь A — одно приложение с Pinx CLI

Установите [Pinx CLI](./pinx-cli.md) один раз, создайте новое приложение и запустите его:

```bash
composer global require pinoox/pinx-cli

pinx new my-shop              # предложит com_my_shop — подтвердите или измените в мастере
cd my-shop
cp .env.example .env          # задайте DB_*, если используете базу данных
pinx setup                    # миграция платформы + приложения, запуск сидеров
pinx dev                      # http://127.0.0.1:8000
```

Или без глобальной установки, через шаблон проекта:

```bash
composer create-project pinoox/app my-shop
cd my-shop
cp .env.example .env
pinx setup
pinx dev
```

Запускайте `pinx doctor` в любой момент, чтобы проверить PHP, окружение, БД и готовность сборки. Полный рабочий процесс и справочник команд смотрите в [руководстве по Pinx CLI](./pinx-cli.md).

## Путь B — полная платформа (классический)

### 1. Получите проект

```bash
git clone https://github.com/pinoox/pinoox.git
cd pinoox
composer install
```

Либо скачайте последний релиз с [GitHub](https://github.com/pinoox/pinoox), распакуйте его и выполните `composer install`.

---

### 2. Разместите его на веб-сервере

Поместите папку проекта в корневую директорию документов:

| Окружение | Пример пути |
|-------------|--------------|
| MAMP | `C:/MAMP/htdocs/pinoox` |
| XAMPP | `C:/xampp/htdocs/pinoox` |
| WAMP | `C:/wamp64/www/pinoox` |

Установите document root на **корень проекта** (папку, содержащую `index.php`), а не на подпапку `public`.

---

### 3. Создайте базу данных

```sql
CREATE DATABASE pinoox_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

---

### 4. Запустите установщик

Откройте в браузере:

```
http://localhost/pinoox
```

Запустится системное приложение `com_pinoox_installer`. Шаги в графическом интерфейсе:

1. Проверка требований PHP
2. Принятие лицензионного соглашения
3. Ввод учётных данных базы данных
4. Создание учётной записи администратора
5. Завершение установки

---

### 5. После установки

Основная структура:

```
pinoox/
├── index.php
├── pinoox              ← CLI
├── apps/               ← приложения
├── vendor/pinoox/pincore/  ← ядро
└── config/             ← конфигурация проекта
```

Создайте своё первое приложение:

```bash
php pinoox app:create com_acme_blog
```

---

## Быстрое устранение неполадок

| Проблема | Решение |
|---------|-----|
| Пустая страница | Выполните `composer install` и проверьте журналы ошибок PHP |
| 404 на вложенных маршрутах | Включите mod_rewrite / `.htaccess` |
| Ошибка отсутствующего расширения | Включите ext-mysqli и ext-zip в php.ini |
| Установщик не открывается | Проверьте document root и права на запись в runtime-папках |
