# Tutorial: aplicación de formulario de contacto

[← Volver al índice](../README.md)

Un formulario de contacto es una de las partes más comunes de un sitio web empresarial. En este tutorial **validas** la entrada, **guardas los mensajes** en la base de datos y rediriges a una página de agradecimiento.

**Package:** `com_acme_contact`  
**URL:** `http://localhost/pinoox/contact`  
**Código fuente completo:** [docs/source/contact-form-app/](../../source/contact-form-app/) — copiar a `apps/`
---

## Paso 4 — Rutas

`routes/actions.php`:

```php
<?php

use App\com_acme_contact\Controller\ContactController;
use function Pinoox\Router\action;

action('contact.form', [ContactController::class, 'form']);
action('contact.store', [ContactController::class, 'store']);
action('contact.thanks', [ContactController::class, 'thanks']);
```

`routes/web.php`:

```php
<?php

use function Pinoox\Router\{get, post};

get('/', '@contact.form')->name('home');
post('/send', '@contact.store')->name('contact.store');
get('/thanks', '@contact.thanks')->name('contact.thanks');
```

## Paso 5 — Controller

```bash
php pinoox controller:create ContactController com_acme_contact
```

```php
<?php
namespace App\com_acme_contact\Controller;

use App\com_acme_contact\Model\MessageModel;
use Pinoox\Component\Http\Request;
use Pinoox\Component\Kernel\Controller\Controller;
use Pinoox\Portal\View;

class ContactController extends Controller
{
    public function form()
    {
        return View::render('pages/form', [
            'title' => 'Contact us',
        ]);
    }

    public function store(Request $request)
    {
        $data = $this->validate([
            'name' => 'required|string|max:120',
            'email' => 'required|email|max:180',
            'subject' => 'required|string|max:200',
            'body' => 'required|string|min:10',
        ]);

        MessageModel::create($data);

        return redirect(url('thanks'));
    }

    public function thanks()
    {
        return View::render('pages/thanks', [
            'title' => 'Message received',
        ]);
    }
}
```

> Más adelante puedes notificar a un administrador con [Event + mail](../advanced/mail.md) al `create` — mantén la lógica de envío en un Component.

## Paso 7 — Probar

1. Abre `http://localhost/pinoox/contact`.
2. Envía con un email inválido — error de validación.
3. Formulario válido — redirige a `/contact/thanks`.
4. Comprueba la tabla `com_acme_contact_messages` en phpMyAdmin.
