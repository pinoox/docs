# Pinoox में योगदान देना

[← इंडेक्स पर वापस जाएँ](../README.md)

Pinoox एक ओपन-सोर्स प्रोजेक्ट है। आपके योगदान — बग रिपोर्ट से लेकर pull requests तक — फ्रेमवर्क और इसके दस्तावेज़ीकरण को बेहतर बनाने में मदद करते हैं।

---

## योगदान करने के तरीके

| प्रकार | विवरण |
|------|-------------|
| बग रिपोर्ट | समस्या को दोहराने (reproduce) के चरणों के साथ GitHub Issue |
| फ़ीचर अनुरोध | उपयोग के मामले (use case) का वर्णन करने वाला Issue |
| Pull Request | उपयुक्त रिपॉज़िटरी में बग फ़िक्स या फ़ीचर |
| दस्तावेज़ीकरण | `docs/` के अंतर्गत फ़ाइलों को बेहतर बनाएँ (फ़ारसी या अंग्रेज़ी) |
| ओपन-सोर्स ऐप | समुदाय के लिए एक Pinoox ऐप प्रकाशित करें |

---

## बग रिपोर्ट करना

Issue खोलते समय, इन्हें शामिल करें:

1. **शीर्षक** — समस्या का संक्षिप्त सारांश
2. **दोहराने के चरण (Steps to reproduce)** — चरण-दर-चरण
3. **अपेक्षित व्यवहार** बनाम **वास्तविक व्यवहार**
4. **एनवायरनमेंट** — PHP संस्करण, Pinoox/pincore संस्करण, ऑपरेटिंग सिस्टम
5. **नमूना कोड** — जब संभव हो

[Pinoox GitHub Issues](https://github.com/pinoox/pinoox/issues)

---

## Pull requests

### रिपॉज़िटरीज़

- **pinoox/pinoox** — नमूना प्रोजेक्ट, सिस्टम ऐप्स, लॉन्चर
- **pinoox/pincore** — फ्रेमवर्क कोर (`vendor/pinoox/pincore/`)

कोर के बदलाव pincore में भेजें, केवल अपने प्रोजेक्ट की लोकल `vendor/` कॉपी में नहीं।

### ब्रांच रणनीति (3.x)

- **बग फ़िक्स** → वर्तमान स्थिर ब्रांच (जैसे `3.x`)
- **छोटे, संगत (compatible) फ़ीचर** → वही स्थिर ब्रांच
- **ब्रेकिंग या बड़े बदलाव** → `master` / अगले-संस्करण की ब्रांच

### कोड मानक

- कोड स्टाइल के लिए [PSR-12](https://www.php-fig.org/psr/psr-12/)
- ऑटोलोडिंग के लिए [PSR-4](https://www.php-fig.org/psr/psr-4/)
- PHP 8.2+
- स्पष्ट, आदेशात्मक (imperative) कमिट संदेश (जैसे `Fix route validation for missing actions`)
